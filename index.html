About Me

Hey! I'm a front-end developer based in Morocco. I first got into coding in school, then kept going on my own afterward — building random pages just to see if I could, until it turned into something I actually wanted to get good at.

Since then I've taken on freelance client work, building custom sites from scratch instead of using templates, because I like when a site actually looks and feels like the brand behind it.

Right now I'm sharpening my HTML, CSS, and JavaScript skills and building out projects I'm genuinely proud to show.

Things I've built (more coming soon!)

LumiCanvas ✦

LumiCanvas ✦ is a creative digital drawing web app that lets users draw on a customizable canvas using tools like pencil, eraser, fill bucket, eyedropper, and stickers. It includes features such as brush size and opacity control, symmetry drawing, undo/redo, multiple themes, and PNG export. Built with HTML, CSS, and JavaScript, it focuses on smooth performance, creativity, and an aesthetic, beginner-friendly design.

Lunar Jewels ✦

Lunar Jewels is a retro Y2K-inspired jewelry e-commerce site built for a client, featuring pixel-art accents, Press Start 2P and VT323 fonts, and variant selectors for bracelet groups. It includes a full multi-page shop layout with a cart-to-Instagram checkout flow, letting customers browse products and complete orders directly through Instagram DMs.

Sew Reloved by Angi ✦

Sew Reloved by Angi is a cottagecore-styled e-commerce site built for a handmade baby items shop. It includes a client-side account system, a fabric swatch–to–order form flow, a conditional custom order modal, Stripe Payment Links for gallery items, and a manual quote flow for custom orders — designed to feel warm, handmade, and personal.
